# Midlex Finance / Accountant Portal

Admin creates invoices in Legal Admin; accountants monitor invoices, review bank-transfer receipts, check gateway payment status, and manage receiving accounts in this portal.

The workspace central backend is the shared payment source for workspace sessions. Each account requires an assigned Finance grant. No demo login credentials are provided.

See [payment provider setup](PAYMENT-PROVIDERS.md) for OPay and Moniepoint/Monnify activation, sandbox checks, and bank-transfer setup.

Run locally with `npm ci` and `npm run dev` (port 3010).
